# 💼 Job Portal | MERN Stack Web Application

A full-stack Job Portal application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The project focuses on connecting job seekers and recruiters through a web-based platform and demonstrates practical implementation of full-stack web development concepts.

## 📌 About the Project

The Job Portal is designed to simplify the job search and recruitment process through a centralized web application.

It demonstrates how frontend and backend technologies work together to build a dynamic web application, handle user requests, communicate with databases, and manage application data.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| MongoDB | NoSQL database for storing application data |
| Express.js | Backend web framework and API handling |
| React.js | Frontend user interface development |
| Node.js | Server-side JavaScript runtime |
| JavaScript | Application logic |
| HTML5 & CSS3 | Structure and styling |
| Git & GitHub | Version control and project management |

## 🏗️ MERN Stack Architecture

The application follows a client-server architecture:

- **Frontend (React.js):** Handles the user interface, components, pages and user interactions.
- **Backend (Node.js & Express.js):** Handles server-side logic, API requests and application operations.
- **Database (MongoDB):** Stores and manages application data.
- **API Communication:** Connects the frontend with backend services through HTTP requests.

## ✨ Key Learning Areas

- Full-stack application development using MERN.
- Frontend and backend integration.
- REST API communication.
- Database connectivity and data management.
- Component-based development using React.
- Server-side application development using Node.js and Express.js.
- Understanding client-server architecture.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/priyanshi027/Job-Portal.git
```

### 2. Navigate to the Project Folder

```bash
cd Job-Portal
```

Navigate to the application directory:

```bash
cd jobportal-yt-main/jobportal-yt-main
```

### 3. Install Dependencies

Run the following command in the relevant frontend and backend directories:

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and configure the required environment variables according to your project configuration.

### 5. Run the Application

Use the development command specified in the respective `package.json` files.

```bash
npm run dev
```
